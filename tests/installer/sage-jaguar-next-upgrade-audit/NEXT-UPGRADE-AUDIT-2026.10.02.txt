All three actual platform RAMFS_COPY_BIN lists retain tr and sha256sum.
Jaguar's certificate export appends cmp/mktemp/sha256sum; Sage already
retains those commands because its shared-store export is a no-op.
Strengthened static checker now verifies required commands are retained,
executable, present, and have resolving target ELF interpreter/library closure.
All three pass. Runtime-generated fw_env.config is still a device prerequisite.

Exact incoming switch_to_ramfs copy loop tested in native fixture ash with
actual executable inventory and recording install_bin/install_file boundaries.
supivot is stubbed to stop before pivot. Actual incoming image extraction runs
in host POSIX sh with copy-list-derived tool PATH, target BusyBox hexdump/tr
via QEMU, and actual FIT/capacity checks. Sage capacity uses file-only UBI
geometry. Extraction succeeds for all three immutable images; deliberate
removal of tr refuses before writes. Actual target ARM/ARM64 ash executes tr
when retained and returns 127 without it. Four assertions per image pass.
This does not prove physical install_bin/library copying or RAM pivot.

Actual early_boot for all three skips mount_certs when runtime key.pem and
operational.pem both exist; bootstrap-only runtime invokes restore. This can
leave /certificates unmounted without losing active runtime identity.
Jaguar actual certificate helper passes canonical file-level retention tests:
unmounted UBIFS uses temporary read-only mount, runtime policy wins, restore
retains key, private modes and source protection; corrupt archives, bad bank/
boot binding, unsafe source and wrong mount refuse. All mounts and UBI identity
are stubs; only synthetic local test credentials are generated.
Sage declares zero per-bank certificate LEBs; export/restore return without
mounting or copying the shared volume. Shared-store preservation is by leaving
that volume untouched, not by Jaguar's bank snapshot mechanism. The separately
qualified Sage preserving installer still requires an already verified mounted
store and may safely refuse an unmounted store; this audit does not broaden it.

Frozen .1 Sage and Jaguar platform lists were additionally read and both
already contain tr. Full dynamic tests in this receipt cover .2/.3 only.
