SHA256 0c2e1ec6005678b7a82acb670cc6f0b38210d98a1b30849b44c3300339e593b6
Usage: verified-offline-root output-ledger seed-file [ELF e_machine].
Seeds one per line: required command/absolute executable; ?optional-command;
@/absolute/readable-plugin-or-library. Resolves standard PATH candidates
usr/sbin,usr/bin,sbin,bin, records aliases including directory links in
target namespace, recursively authenticates ELF interpreter/DT_NEEDED closure.
Explicitly seed actual dlopen/ucode imports; DT_NEEDED alone cannot infer them.
Never run generator on live AP or learn hashes from a rejected candidate.
Stock clean route must not require unused OpenSSL or read legacy credentials.

Integration:
SHA-authenticate bundle first; pin live PATH to /usr/sbin:/usr/bin:/sbin:/bin.
Keep exact reviewed implementation tuples/wildcard closure; remove ONLY
/etc/openwrt_release and /etc/cambium-openwrt-release from code fingerprints.
Metadata minimum + runtime ledger + code contract are independent mandatory
gates before sourcing AP code/install writes. Recheck at mutation boundaries;
freeze validated metadata fingerprint within invocation to detect drift.
Recovery restores only authenticated original target bytes, never metadata;
check live tool identities before recovery execution. Inability to qualify
current metadata must not permit new install/flash. Safe rollback handling
must remain explicit and not introduce unknown executable script sourcing.
Retain model/SKU/layout/calibration/vault/RAM/crypto/store/snapshot/compatibility
guards; a valid newer label is not approval of unknown implementation code.
Changed code/tool/library variants require separate offline qualification.
Installer images/published artifacts/AP state remain immutable until own
route receipts and explicit publication/deployment authorization.

ARM64,MIPS BusyBox ash+awk+wc through QEMU (304Linux/target controls).
Runtime matcher15synthetic file/link/permission/absence controls on macOS and
Linux. Actual Sage/Jaguar archived tool closure ledgers generate and match;
their route-specific seeds/ledger receipts are separate, not generic hardware
