Cheetah source tools

Deliberate verification, test, integration and release-packaging scripts retained from the qualified .11/.12/.13 work. Script defaults identify their historical version and original owned build layout; review/update those arguments for new releases. Required generated build roots, firmware inputs and runtime fixtures are supplied locally, not published here. Canonical shared DFS/discovery source fixtures remain in the repository tests directories. Packaging tools generate artifacts only when explicitly invoked for a new authorized release.

This source-only feature branch includes no generated configurations, result receipts, snapshots, source diffs, firmware, archives or private data. No tool was executed as a firmware build or AP operation during preservation. Repository owner decides main integration after review.
